# Malaria Vector Surveillance Toolkit

## Overview

This is an open-source research project investigating DDT resistance and sibling species composition of *Anopheles gambiae* s.l. in selected communities in Accra, Ghana.

This repository contains the documentation, analysis scripts, and resources used throughout the project.

---

## Project Status

🚧 Under Development

Current progress:

- Literature review completed
- Research proposal completed
- Methodology finalized
- Preparing for mosquito collection

---

## Objectives

1. Determine DDT resistance using WHO tube bioassays.
2. Identify sibling species using molecular techniques.
3. Develop reproducible analysis workflows.
4. Share tools and documentation with researchers.
